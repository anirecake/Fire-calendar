# Выступление: 30 с видео + 2,5 мин слайды + 2 мин вопросы

## 1. Видео 30 секунд (динамичное, без голоса, английские титры)

Принцип: 8 коротких кадров по 3–5 секунд, каждый показывает **одну** вещь. Титр — максимум 6–7 слов,
крупно, белым на чёрной плашке внизу. Переходы — резкие склейки (без «эффектов»), ритм под музыку.

| Время | Что на экране | Титр (English) |
|---|---|---|
| 0:00–0:04 | Тёмная карта Центральной Азии, жмём «Показать по годам» — тепловая карта меняется год за годом (ускорить ×4) | **26 years of NASA fire data** |
| 0:04–0:08 | Вкладка «Тренд», включить «Показать сырые данные спутников»: виден ложный скачок в 2012 и ровная пересчитанная линия | **Two satellites. One consistent record.** |
| 0:08–0:12 | Выбор: Казахстан → Восточно-Казахстанская область. Область подсвечивается, справа ответ «на 138% больше обычного» | **Is it burning more than usual?** |
| 0:12–0:16 | Режим «ЧС-службы» → «Опасность возгорания» → вид «Плавно», затем «Клетки», список «Самые опасные места» | **AI forecast: 14 days, down to 25 km** |
| 0:16–0:20 | Вкладка «Что делать»: ИИ-разбор, медленный скролл по мерам (кто / что / когда) | **AI briefing for emergency services** |
| 0:20–0:24 | Открыть ИИ-помощника, вопрос «Where is the risk highest?», ответ и карта сама переезжает (ускорить ×2) | **Ask in Kazakh, Russian or English** |
| 0:24–0:27 | Телефон: приходит push «FireCalendar alerts are on» / сообщение бота в Telegram | **Alerts when a fire starts near you** |
| 0:27–0:30 | Чёрный экран: логотип FIRECALENDAR, адрес сайта, «NASA Space Apps 2026» (и переключатель «Central Asia / USA», если сайт США уже опубликован) | **fire-calendar.vercel.app** |

### Как снять, чтобы выглядело дорого
- Язык сайта для видео — **English** (жюри в США). Тёмная тема. Браузер на весь экран (F11), масштаб 110–125%,
  без закладок и лишних вкладок, курсор двигать плавно.
- Снимать **каждый кадр отдельно** по 6–10 секунд (Win+G / OBS, 1920×1080, 30 или 60 fps), потом резать в CapCut.
- **Заранее прогреть ИИ**: один раз открыть «Why» и «What to do» у Восточно-Казахстанской области на английском
  (первый разбор готовится ~30 с, потом открывается мгновенно). Так же один раз задать вопрос помощнику.
- Push для кадра 7: на телефоне открыть сайт → «Alerts» → включить → «Send a test». Снять экран телефона записью экрана.
- Музыка без авторских прав (YouTube Audio Library, раздел «Cinematic»/«Electronic», ~120 BPM); склейки на долю.
- Экспорт: MP4 1080p, загрузить на YouTube (по ссылке) или Google Drive с открытым доступом — для поля «Project Demo».
- Если голос — только на английском или с английскими субтитрами (требование Space Apps).

## 2. Слайды на 2,5 минуты (5 слайдов, ~30 с на каждый)

1. **Проблема (0:30–1:00).** MODIS (2000→, 1 км) и VIIRS (2012→, 375 м, видит в 3–4 раза больше) — при склейке
   ложный скачок в 2012. В Центральной Азии каждый год горят степь, тростник, стерня; июнь 2023 — гибель лесников
   в области Абай. Нельзя понять, горит ли больше обычного.
2. **Решение и проверка (1:00–1:30).** Пересчёт MODIS→VIIRS по клеткам 25 км и месяцам. Проверка на годах, которых
   модель не видела: R² 0,99 по региону, смещение +0,8%. Главный вывод: **−60% за десятилетие** с 2001 года —
   по одному VIIRS это не доказать (p = 0,10).
3. **Продукт (1:30–2:00).** Три режима: Для всех / ЧС / Аналитик. 395 тыс. пожаров со свойствами (пожар в Абае
   2023 найден автоматически). Выгрузка CSV/PNG, открытый API, три языка.
4. **ИИ (2:00–2:30).** Две свои модели: по областям AUC 0,81, по местам ~25 км AUC 0,84 (обучены на NASA POWER +
   FIRMS). Claude — только интерфейс над нашими данными: чат-помощник и разбор с мерами для ЧС, цифры не выдумывает.
   Оповещения в браузере и Telegram.
5. **Влияние и дальше (2:30–3:00).** Для ЧС и акиматов — где и когда готовиться; для людей — понятный ответ и
   оповещения на казахском. Метод глобальный: уже собрана версия для США. Дальше: ежедневное автообновление,
   интеграция с МЧС, весь мир. Ссылка + QR.

Совет: на слайдах — одна мысль, одна цифра, один скриншот. Текст говорите, а не читайте.

## 3. Вопросы жюри — короткие ответы

| Вопрос | Ответ |
|---|---|
| Как проверяли гармонизацию? | Учили на 2012–2018, предсказывали VIIRS по MODIS на 2019–2021, которых модель не видела. R² 0,99 по региону, смещение +0,8%; есть 90% интервалы, покрытие 94%. |
| Почему тренд не виден только по VIIRS? | VIIRS начинается в 2012 — всего 13 лет, слишком мало для значимого теста (p = 0,10). С пересчитанным MODIS — 25 лет, p < 0,0001. |
| Прогноз лучше, чем просто «сезон»? | Да: AUC 0,81 против 0,63 у прогноза по сезону; когда модель говорит «высокий», пожаров больше обычного в 53% случаев против 12%. |
| Что делает ИИ-ассистент, не выдумывает ли? | Claude не считает сам: он вызывает наши функции (модель риска, статистику, список пожаров) и пересказывает их результат. В ответе видно, какие данные использованы. |
| Насколько свежие данные? | Сейчас снимок по 13 ноября. FIRMS отдаёт данные с задержкой ~3 часа, сбор можно запускать по расписанию ежедневно — это следующий шаг. |
| Газовые факелы не дают ложных тревог? | Мы исключаем 1 792 известных постоянных источника тепла по 26-летнему архиву NASA (тип «статичный источник»). |
| Как масштабируется? | NASA FIRMS и POWER покрывают всю Землю; страна добавляется настройкой. Версия для США уже собрана (50 штатов). |
| Кто будет пользоваться? | Областные ДЧС и акиматы (где и когда усиливать патрули), исследователи и лесные службы (данные), жители (оповещения). |
| Ограничения? | Спутник видит тепло, а не причину; облака и дым скрывают очаги; «площадь» — это площадь активного горения, а не выгоревшая территория; границы областей до реформы 2022 года. |
| Почему клетки 25 км? | Компромисс: достаточно данных в каждой клетке для оценки соотношения MODIS/VIIRS и при этом видно детали внутри областей. |
